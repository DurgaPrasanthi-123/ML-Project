How The Detection Engine Works

Our architecture evaluates URLs completely offline and passively, ensuring maximum user privacy and zero risk of payload activation.

1️⃣

Passive URL Ingestion

The user inputs any web link. The system safely sanitizes and parses the URL into its fundamental protocol, hostname, port, path, and query components without executing network requests.

2️⃣

17-Vector Feature Extraction

A deterministic parser extracts quantitative indicators such as domain length, IP presence, subdomain depth, token frequency, special character ratios, and brand spoofing patterns.

3️⃣

Random Forest Inference

The calibrated ensemble model computes tree votes across 120 decision trees to classify the URL into Legitimate or Phishing, assigning an exact confidence probability score.
